# Week 2 Python Debugging Task

## Contents

- `original_buggy_task_tracker.py`: deliberately faulty source used for the debugging exercise.
- `corrected_task_tracker.py`: corrected command-line task tracker.
- `test_corrected_task_tracker.py`: automated unit tests.
- `DEBUGGING_LOG.md`: detailed record of findings, causes, fixes, and testing.

## Run the Corrected Application

```bash
python corrected_task_tracker.py
```

## Run the Tests

```bash
python -m unittest test_corrected_task_tracker.py
```

## Requirements

Python 3.10 or later. No external packages are required.
